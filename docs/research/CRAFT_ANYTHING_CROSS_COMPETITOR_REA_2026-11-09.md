# Craft Anything — Actual Deep REA Across Five Slide Competitors

**Date:** 2026-11-09. **Target:** TheHalfMoon/Gomri. **Tool:** [storytold/craft-anything](https://github.com/storytold/craft-anything), native Windows portable v0.6.0. Its release ZIP was downloaded from GitHub and SHA256-verified against the official release checksum before execution. Actual CLI and MCP calls were made on the authorized Windows computer.

This is a tool-backed reverse-engineering investigation, NOT a reconstructed proprietary engine, login bypass, or comparison of private editor outputs. Craft Anything was used in Deep mode with a *fresh signed-out browser*, plus static analysis of code publicly available on GitHub. Captured HTML, screenshots and vendor web JS were kept locally, NOT reproduced in this public Gomri branch.

## 6. Technical limitations and security

- Deep mode was used for permitted public JS and public GitHub source; fresh anonymous browser sessions were deliberately used. No account/session bypass.
- Craft Anything is early alpha. A count of string literals matching URL route/endpoint patterns can include telemetry, marketing, docs and dead code. It cannot be called an authenticated production API inventory.
- Gamma/GPT Slides website challenges were not bypassed. No confidential account source, private NextSlide code, full Beautiful SmartLayout source or modern VistaCreate private GitLab engineering kit was accessed.
- We did not generate competitor decks, spend credits, install their legacy dependencies, test feature parity, or modify Gomri runtime code in this research branch.
- All screenshots/HTML/JS from public sites remained local and are not redistributed. Source packages used for static inspection were exact public commits that previous Gomri research separately analyzed for rights.
- These findings **do not prove Gomri beats the competitors**. Only head-to-head synthetic editor tests, native PPTX diff, aesthetics blind reviews, source provenance and exact tested head can support such a claim.
